# Template Data Awal Pedoman

Gunakan template ini untuk mengisi 10–20 pedoman yang paling sering dipakai agent. Satu pedoman diisi sebagai satu bagian.

Produk arsip tidak perlu dimasukkan ke daftar awal. Update yang hanya berlaku sementara dibuat melalui menu **Update Sementara**, bukan dengan mengubah pedoman utama.

## Cara mengisi

- Pakai kalimat yang biasa dipakai agent saat chat.
- Satu judul hanya membahas satu kondisi pelanggan.
- Skrip harus siap disalin dan dikirim setelah agent melakukan pengecekan.
- Jika tidak ada eskalasi, isi jenis tindakan **Selesai di Tier 1**.
- Kolom yang belum diketahui boleh dikosongkan dan ditandai untuk dilengkapi.

## Formulir satu pedoman

| Bagian | Isi |
|---|---|
| Judul pedoman | Contoh: Pembayaran cicilan belum masuk lebih dari 1×24 jam |
| Produk | Contoh: Akulaku Paylater |
| Kategori | Contoh: Tagihan & Pembayaran |
| Sub tipe tiket | Contoh: DP/Cicilan belum masuk |
| Kondisi pelanggan | Apa yang dialami pelanggan? |
| Yang perlu ditanyakan atau dicek | Pertanyaan/verifikasi yang wajib dilakukan agent |
| Skrip Live Chat | Kalimat siap kirim ke pelanggan |
| Langkah agent | Urutan tindakan agent dari awal sampai selesai |
| Jenis tindakan | Selesai di Tier 1 / Buat tiket / Eskalasi Tier 2/3 / Transfer ke ASI / Referensi saja |
| Tim tujuan | Diisi jika perlu eskalasi atau transfer |
| Status CRM | Contoh: Menunggu Diproses |
| Peringatan | Hal yang tidak boleh dilakukan atau kondisi khusus |
| Tandai sebagai update penting? | Ya / Tidak |
| Sumber informasi | Nama dokumen atau tim pemberi informasi |
| Tanggal berlaku | Tanggal mulai digunakan |
| Tanggal berakhir | Kosongkan jika tidak ada batas waktu |
| PIC | Nama pemilik konten |
| Status | Draft / Published / Perlu diperiksa |

## Contoh pengisian

**Judul pedoman:** Pembayaran cicilan belum masuk lebih dari 1×24 jam  
**Produk:** Akulaku Paylater  
**Kategori:** Tagihan & Pembayaran  
**Sub tipe tiket:** DP/Cicilan belum masuk  
**Kondisi pelanggan:** Pelanggan sudah membayar cicilan lebih dari 1×24 jam, tetapi pembayaran belum masuk dan tagihan masih tampil.  
**Yang perlu ditanyakan atau dicek:** Minta nomor pesanan/kontrak, bukti pembayaran, tanggal dan nominal pembayaran, lalu pastikan sudah melewati 1×24 jam.  
**Skrip Live Chat:** Untuk menindaklanjuti kendala yang Kakak alami, mohon mengirimkan bukti pembayaran yang menampilkan tanggal, nominal, serta metode pembayaran.  
**Langkah agent:** Terima bukti pembayaran → cek status pada console → buat tiket dan eskalasikan jika memenuhi syarat.  
**Jenis tindakan:** Eskalasi Tier 2/3  
**Tim tujuan:** CS FU Jakarta  
**Status CRM:** Menunggu Diproses  
**Peringatan:** Jangan menjanjikan waktu penyelesaian sebelum ada konfirmasi dari tim tujuan.  
**Tandai sebagai update penting?:** Tidak  
**Sumber informasi:** Tim Payment Operations  
**Tanggal berlaku:** 2026-08-06  
**PIC:** Admin KM  
**Status:** Draft
